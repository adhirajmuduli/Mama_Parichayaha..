# docs/history — archived planning documents

These files are the **superseded** planning documents of the PP8.1 rewrite. They
are kept for provenance only: nothing in `src/`, `tests/`, `scripts/` or
`docs/adr/` depends on them, and they are **not** maintained.

| File                                          | Era         | What it planned                                                        |
| --------------------------------------------- | ----------- | ---------------------------------------------------------------------- |
| `plan.md`                                     | pre-rewrite | original boilerplate roadmap (React Three Fiber scene, model pipeline) |
| `plan2.md`                                    | pre-rewrite | static reachability audit of the boilerplate + findings list           |
| `plan(3).md`                                  | 2026-08     | five-chapter cyclic restructure with model groups                      |
| `plan3.md`                                    | 2026-08     | restructure execution checklist                                        |
| `plan4.md`                                    | 2026-08     | latest user direction (immersive, chrome-free journey)                 |
| `plan4-progress.md`                           | 2026-08     | progress log for `plan4.md`                                            |
| `plan_refactor.md`                            | pre-rewrite | reachability audit of the boilerplate codebase                         |
| `plan_restructuring.md`                       | 2026-08     | closed cyclic journey + spatial clouds spec                            |
| `action_plan.md`                              | pre-rewrite | ordered action list for the boilerplate                                |
| `portfolio_completion_and_deployment_plan.md` | pre-rewrite | completion + deployment runbook (3D era)                               |
| `clean_tree.txt`                              | pre-rewrite | repo tree snapshot after a cleanup pass                                |
| `tree.txt`                                    | pre-rewrite | full repo tree snapshot (3.5 MB)                                       |

The **living** documents are:

- `new_plan.md` (repo root) — the execution plan for the current architecture.
- `docs/adr/*` — the decision log. ADRs 0001, 0005, 0006, 0008 and 0009 were
  superseded by the ASCII/DOM-only direction; ADR 0010 and ADR 0011 record it.
- `docs/phase*.md` — per-phase verification notes.
- `docs/architecture/*`, `docs/ops/*`, `docs/evidence/*` — current reference.

Archived in P11 (see `new_plan.md` §14, P11 and §20 changelog).
