# ADR 0010: ASCII Exhibit Medium

- Status: Accepted
- Date: 2026-10-18
- Supersedes: ADR 0005 (model budget exception and tier policy), ADR 0006 (active DNA asset budget exception), ADR 0008 (spatial clouds and local model halos), ADR 0009 (testing-phase real-asset policy)

## Context

The site shipped as a React Three Fiber portfolio: five chapters, each with a
GLB/GLTF model served from `public/models/`, a scene graph with cameras, lights
and postprocessing, and a deploy footprint dominated by binary assets
(~142 MB) plus `@react-three/*` and `postprocessing`.

The owner's direction changed on 2026-10-18: the exhibits are **ASCII text
animations** rendered in the DOM. The real animation sources arrive later; the
repository must ship the player, the source-adapter contract and honest
placeholder art without guessing at the owner's frames.

Keeping both media was considered and rejected: a dual exhibit pipeline keeps
the WebGL dependency, the model budget, the asset provenance question and the
per-chapter 3D performance cost alive for a medium that is no longer used.

## Decision

1. **The exhibit medium is ASCII text.** Every chapter visual is a mono grid
   rendered into a `<pre class="ascii-panel__frame">`; the grid contract
   (rows, columns, deterministic frames, fixed metrics) is defined in
   `docs/architecture/ascii-contract.md`.
2. **No 3D pipeline.** `@react-three/fiber`, `@react-three/drei`,
   `@react-three/postprocessing` and `postprocessing` are removed from
   `package.json` and the lockfile. There is no scene layer, no camera, no
   model loader, no Draco pipeline and no served GLB.
3. **The player is source-agnostic.** `exhibits/sources/<chapter>.ts` adapters
   implement `AsciiExhibitSource`; `AsciiFramePlayer` renders frames from any
   adapter without change. Owner-supplied animations drop into that contract
   without touching the player, the stage layout or the scheduler.
4. **Placeholder art is honest.** Until real sources land, the panel renders
   deterministic placeholder frames generated by
   `exhibits/sources/placeholder.ts` (seeded, SSR-stable). The frame is
   labelled `data-placeholder="true"` and the mock-era sources are labelled
   `data-mock="true"` so the difference is inspectable, not implied.
5. **GLB binaries are archive-only.** The former model files stay in the
   repository under `assets/models/source/` for provenance. Nothing in
   `public/` and nothing in the runtime references them; they are not
   deployed.
6. **One sanctioned 3D island remains.** The react-bits Lanyard in the origins
   slot is the only WebGL surface in the product (see ADR 0011). It is lazily
   imported, capability-gated and self-parking; `three` is imported nowhere
   else — enforced by `scripts/quality/check-boundaries.mjs` and the bundle
   budget check.

## Consequences

Deploy weight loses the model binaries; the runtime loses the scene layer and
its frame-time cost; the exhibit surface becomes text, which is cheap to
render, style with the site's own tokens and read with a screen reader. The
cost is that the shipped placeholders are not the owner's animations: the
integration contract is complete and tested, but the final art still depends
on the owner's sources (P9b). Provenance for the archived binaries is
preserved instead of being deleted with the pipeline.
